# Gotham Rounded ScreenSmart Font Files

Place your Gotham Rounded ScreenSmart font files in this directory.

Required files:
- GothamRoundedScreenSmart-Book.woff2 (weight 400)
- GothamRoundedScreenSmart-Medium.woff2 (weight 500)
- GothamRoundedScreenSmart-Bold.woff2 (weight 700)

These files are referenced in src/styles/global.css via @font-face declarations.

If you only have .ttf or .otf files, convert them to .woff2 using a tool like:
- https://cloudconvert.com/ttf-to-woff2
- https://fonts.google.com/ (not applicable for Gotham)
- FontForge or Transfonter

The font files should be placed directly in this folder (public/fonts/gotham-rounded/).
